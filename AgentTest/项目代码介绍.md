# ReActAgentsTest 项目代码详细介绍

## 一、Python版本要求

### 推荐版本：**Python 3.10 或更高版本**

### 版本要求分析

通过扫描项目代码，发现以下关键特性：

1. **联合类型语法（PEP 604）**：代码中使用了 `Callable | BaseTool` 和 `str | None` 这种联合类型语法，这是Python 3.10引入的特性
   - 示例位置：`02_ReActAgentHILTest/02_reviewMCPToolCalls.py` 第33行
   - 示例位置：`04_ReActAgentHILApiTest/utils/tools.py` 第42行

2. **内置泛型类型**：使用了 `tuple[...]` 语法（Python 3.9+，但为了与联合类型兼容，推荐3.10+）
   - 示例位置：`04_ReActAgentHILApiTest/utils/llms.py` 第75行

3. **现代异步编程**：大量使用 `async/await` 语法

4. **类型提示**：全面使用类型注解和类型提示

### 不兼容的版本
- **Python 3.9 及以下**：不支持联合类型 `|` 语法，必须使用 `Union` 或 `Optional`

## 二、项目整体架构

本项目是一个基于 **LangGraph** 框架的 **ReAct Agent（推理-行动 Agent）** 测试和演示项目，展示了从基础功能测试到完整API服务的演进过程。

### 项目演进路线

```
01_ReActAgentAmapMCPServerTest  (基础：MCP Server集成)
    ↓
02_ReActAgentHILTest            (进阶：人工审查功能)
    ↓
03_ReActAgentMemoryTest          (进阶：记忆管理)
    ↓
04_ReActAgentHILApiTest          (服务：单用户单会话API)
    ↓
05_ReActAgentHILApiMultiSessionTest  (服务：多用户多会话API)
    ↓
06_ReActAgentHILApiMultiSessionTaskTest  (服务：多用户多会话多任务异步调度)
```

### 3.2 02_ReActAgentHILTest

**功能定位**：人工审查（Human-in-the-Loop）功能测试

**核心功能**：
- 实现工具调用的人工审查机制
- 支持三种反馈方式：accept（接受）、edit（编辑参数）、response（直接反馈）
- 支持自定义工具和MCP工具的人工审查

**关键技术**：
- `langgraph.types.interrupt`：中断机制
- `langgraph.prebuilt.interrupt.HumanInterruptConfig`：人工中断配置
- `Command(resume=[...])`：恢复中断的执行

**主要文件**：
- `01_reviewCustomToolCalls.py`：测试自定义工具的人工审查
- `02_reviewMCPToolCalls.py`：测试MCP工具的人工审查
- `03_reviewMixToolCalls.py`：测试混合工具的人工审查

**核心实现**：
```python
async def add_human_in_the_loop(tool: Callable | BaseTool, ...):
    """为工具添加人工审查功能"""
    @create_tool(...)
    async def call_tool_with_interrupt(config, **tool_input):
        request: HumanInterrupt = {...}
        response = interrupt([request])[0]
        
        if response["type"] == "accept":
            tool_response = await tool.ainvoke(tool_input, config)
        elif response["type"] == "edit":
            tool_input = response["args"]["args"]
            tool_response = await tool.ainvoke(tool_input, config)
        elif response["type"] == "response":
            tool_response = response["args"]
        
        return tool_response
    
    return call_tool_with_interrupt
```

**人工反馈模拟**：
```python
# 接受工具调用
agent.invoke(Command(resume=[{"type": "accept"}]), config)

# 编辑工具参数
agent.invoke(Command(resume=[{
    "type": "edit", 
    "args": {"args": {"hotel_name": "汉庭酒店(软件园店)"}}
}]), config)

# 直接反馈
agent.invoke(Command(resume=[{
    "type": "response", 
    "args": "我不想预定这个酒店了"
}]), config)
```

### 3.3 03_ReActAgentMemoryTest

**功能定位**：记忆管理功能测试

**核心功能**：
- **短期记忆（Short-term Memory）**：使用PostgreSQL存储对话上下文
- **长期记忆（Long-term Memory）**：使用PostgreSQL Store存储用户偏好和配置
- 支持消息修剪（trim_messages）以控制token数量

**关键技术**：
- `langgraph.checkpoint.postgres.aio.AsyncPostgresSaver`：短期记忆存储
- `langgraph.store.postgres.AsyncPostgresStore`：长期记忆存储
- `langchain_core.messages.utils.trim_messages`：消息修剪

**主要文件**：
- `01_shortTermTest.py`：测试短期记忆功能
- `02_longTermTest.py`：测试短期+长期记忆功能

**存储结构**：
```python
# 短期记忆：存储对话状态
checkpointer = AsyncPostgresSaver(pool)
config = {"configurable": {"thread_id": "1"}}

# 长期记忆：存储用户偏好
store = AsyncPostgresStore(pool)
namespace = ("memories", user_id)
await store.aput(namespace, key, {"data": memory_info})
```

**消息修剪示例**：
```python
def pre_model_hook(state):
    trimmed_messages = trim_messages(
        messages=state["messages"],
        max_tokens=4,
        strategy="last",
        token_counter=len,
        start_on="human",
        include_system=True
    )
    return {"llm_input_messages": trimmed_messages}
```

## 四、核心技术组件

### 4.1 LangGraph框架

**核心概念**：
- **Agent**：基于ReAct模式的智能体
- **Checkpointer**：状态检查点管理器（短期记忆）
- **Store**：长期记忆存储
- **Interrupt**：中断机制（人工审查）

**关键API**：
```python
from langgraph.prebuilt import create_react_agent
from langgraph.checkpoint.postgres.aio import AsyncPostgresSaver
from langgraph.store.postgres import AsyncPostgresStore
from langgraph.types import interrupt, Command
```

### 4.2 数据库设计

**PostgreSQL**：
- **短期记忆表**：由 `AsyncPostgresSaver.setup()` 自动创建
- **长期记忆表**：由 `AsyncPostgresStore.setup()` 自动创建

**Redis**：
- **会话管理**：存储会话状态、任务状态
- **任务映射**：维护用户-会话-任务的关联关系

### 4.3 工具系统

**工具类型**：
1. **自定义工具**：使用 `@tool` 装饰器定义
2. **MCP工具**：从MCP Server获取

**工具包装**：
- 所有工具都可以添加人工审查功能
- 通过 `add_human_in_the_loop` 函数包装

### 4.4 日志系统

**日志配置**：
- 使用 `ConcurrentRotatingFileHandler` 支持并发写入
- 日志文件大小限制：5MB
- 保留历史文件数：3个
